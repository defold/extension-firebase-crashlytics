Follow guide in https://github.com/defold/extension-firebase

Crashlytics SDK versions are declared in `firebase_crashlytics/manifests/android/build.gradle`, `firebase_crashlytics/manifests/ios/SwiftPackages.json`, and `firebase_crashlytics/manifests/osx/SwiftPackages.json`.
Keep these versions aligned with the Firebase SDK version used by the main Firebase extension.
